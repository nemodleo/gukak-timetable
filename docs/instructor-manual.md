# 강사 매뉴얼

강사가 하는 일 — **시간표 보기 · 학생 배정 · 메모 · 통계 열람**을 정리했습니다.
명단·목표시수·강의실 구조·비활성 칸·설정은 관리자만 다룹니다([관리자 매뉴얼](admin-manual.md) 참고).

> 화면은 익명 예시 데이터(`학생01 (교사AT)` …)로 촬영했습니다.

---

## 1. 로그인

화면 오른쪽 위 **강사** 버튼 → 강사 비밀번호 입력.

![헤더 로그인 팝오버](manual/login-popover.png)

- 로그인 상태는 브라우저에 **30일** 유지됩니다. 공용 PC에서는 작업 후 **로그아웃**.
- macOS에서 비밀번호 칸이 한글로 안 바뀌는 것은 OS 제약입니다 — 비밀번호는 영문·숫자로 받으세요.

---

## 2. 화면 구성

![상단 내비게이션 바](manual/nav.png)

- **시간표**(로고) → 월간 달력, **월간 / 통계** → 뷰 전환.
- 모든 시간표·통계 화면에서 <kbd>←</kbd> <kbd>→</kbd> 로 이전/다음(달·주·날짜)으로 이동합니다.
  입력칸에 커서가 있으면 동작하지 않습니다.

세 뷰를 오가며 봅니다.

- 월간에서 **"N주"** 클릭 → 그 주의 주간 시간표.
- 월간·주간에서 **날짜** 클릭 → 그 날의 일간 시간표.
- 일간 화면 오른쪽 위 **주간 보기** → 그 주로 복귀.

**월간 달력** — 날짜 칸의 막대는 포화도(수업이 얼마나 찼는지), 숫자는 그 날 수업 개수, ✕는 수업을 넣을
수 있는 시간이 없는 날입니다.

![월간 달력](manual/month.png)

## 3. 주간·일간 시간표

![주간 시간표 편집 화면](manual/week.png)

- **보기 / 편집 토글** — 칸을 바꾸려면 먼저 **편집**을 눌러야 합니다. *보기*는 실수 방지용 읽기 모드.
- **격자** — 하루당 6강의실(`I · II · III · 大 · 中 · 우`) × 시간블록.
- **칸 색** = 학년 — 🟨 1학년 · 🟥 2학년 · 🟩 3학년 · 🟦 보강·합반. 사선 빗금 = *비활성*(수업 없는 시간, 관리자가 지정).
- **이미지 저장** — 주간은 *주 전체 저장 (zip)*, 일간은 *이미지 저장*(1장), 월간은 *월 전체 저장 (zip)*.
- 아래 **일별 보기** 칩으로 각 날짜 일간 화면으로.

## 4. 학생 배정하기

1. **편집** 모드에서 넣을 칸(빈 칸 또는 기존 배정)을 클릭 → 편집 창이 열립니다.
2. **학생(교사)** 탭에서 검색창으로 좁힌 뒤 목록에서 선택 → **저장**.

<img src="manual/cell-pairing.png" alt="칸 편집 창 — 학생(교사) 탭" width="420" />

- 목록에는 그 칸 **날짜가 속한 달의 명단**만 나옵니다. 찾는 학생이 없으면 관리자에게 그 달 명단에 추가를
  요청하세요.
- **수업 시간 옮기기** — 새 칸에 그 학생을 배정하고 저장한 뒤, 원래 칸을 클릭 → **칸 비우기**(편집 창
  왼쪽 아래, 빨강).

### 되돌리기

![편집 툴바](manual/toolbar.png)

툴바의 **↶ 이전** 또는 <kbd>⌘ / Ctrl</kbd> + <kbd>Z</kbd> 로 마지막 편집을 취소합니다.

> 강사는 **비활성(회색) 칸**은 만들 수 없습니다(툴바의 *비활성 지정*은 관리자 전용). 수업을 넣지 않을
> 시간대 지정은 관리자에게 요청하세요.

---

## 5. 메모

주간·일간 화면 오른쪽 **메모 열**은 30분 줄 단위 자유 메모입니다.

- 입력하면 **즉시 자동 저장**됩니다(저장 버튼 없음).
- 줄에 커서를 두거나 내용이 있으면 그 줄의 **빨강 강조** · **글자 크기** 토글이 나타납니다.

---

## 6. 통계

![통계 화면](manual/stats.png)

로그인하면 상단에 **통계** 메뉴가 생깁니다. <kbd>←</kbd> <kbd>→</kbd> 로 달을 바꿉니다.

- **목표 차이** — 학생(교사)별 실배정 · 목표 · 차이. 초과는 빨강, 미달은 주황. 정렬은 초과 많은 순 →
  미달 많은 순 → 일치 → 목표 미입력.
- **페어링 × 요일 · 주차** — 학생(교사)별로 요일·주차에 배정된 시간과 합계.

---

## 7. 강사가 할 수 없는 것 → 관리자에게

| 필요한 일 | 요청 대상 |
| --- | --- |
| 그 달 명단에 학생 추가 / 교사·목표시수 변경 | 관리자 (명단 탭) |
| 비활성(수업 없는) 시간대 지정 | 관리자 (비활성 탭 / 비활성 지정) |
| 강의실 · 시간블록 추가·삭제·시간 변경 | 관리자 (격자 머리글) |
| 학교명·기준 월·주 시작 요일 등 설정 | 관리자 (설정 탭) |
| 엑셀 데이터 가져오기 / 백업 | 관리자 (데이터 탭) |

---

## 8. 문제 해결

| 증상 | 해결 |
| --- | --- |
| 칸이 안 눌림 / 편집이 안 됨 | 화면의 **편집** 토글을 눌렀는지 확인. 로그인이 풀렸을 수도 있습니다. |
| "데모 모드" 배너 | 데이터베이스 미연결 상태 — 저장이 안 됩니다. 관리자에게 문의. |
| 배정하려는 학생이 목록에 없음 | 그 **달 명단**에 없는 것 — 관리자에게 추가 요청. |
| 통계 메뉴가 안 보임 | 로그인이 풀렸습니다. 다시 로그인하세요. |
| 이미지 저장이 느림 | 브라우저 탭을 화면에 띄운 채로 기다리세요. |
